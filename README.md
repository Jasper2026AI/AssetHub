# AssetHub 个人资产可视化系统 v3.0

双击 `index.html` 即可在浏览器打开（推荐 Chrome / Edge / Safari）。无需安装、无需服务器。
数据保存在浏览器本地（localStorage），也可通过 GitHub Gist 在多台设备间同步。

---

## 一、文件结构

```
AssetHub/
├─ index.html              页面入口（双击打开）
├─ README.md               本说明
├─ .nojekyll               部署到 GitHub Pages 用（保持即可）
└─ assets/
   ├─ img/logo.png         品牌图标（木牛，透明底）；favicon.png 为浏览器标签图标
   ├─ css/style.css        全部样式（颜色变量在文件顶部 :root）
   └─ js/
      ├─ i18n.js           中英文字典（改任何界面文字都在这里）
      ├─ charts.js         圆环图 / 折线图 / K 线图（纯 SVG，离线可用）
      ├─ api.js            行情、汇率、GitHub Gist 接口
      └─ app.js            主程序（顶部“常量与配置”可改币种、类别、分类、配色）
```

## 二、功能一览

| 页面 | 主要功能 |
|---|---|
| 顶栏 | 云同步、币种切换、刷新行情、盈亏配色切换、隐藏金额、中 / 英、电脑 / 手机 |
| 资产总览 | 总资产与日 / 月 / 年盈亏；各类别总盈亏与日盈亏；资产占比 / 资产排行；日变化 / 总变化排行；资产趋势（K 线 / 实线，月内 / 年内 / 日线）与收支趋势；最近收支 |
| 资产明细 | 搜索、类别筛选、排序；今日盈亏 / 浮动盈亏；资产仓库；更新市值 / 余额；批量删除、锁仓；操作记录 |
| 收支明细 | 日 / 月 / 年统计；按日期、类型、分类、账户、备注筛选；金额排序；转账（含手续费、跨币种）；默认锁定；批量删除；操作记录 |
| 数据设置 | 账本名、导入 / 导出、演示数据；安全与锁定；操作日志；多端同步；行情源；外观 |

## 三、行情与汇率（均为免费接口）

| 用途 | 接口 | 是否需要 Key |
|---|---|---|
| 汇率 | open.er-api.com（备用 jsDelivr currency-api） | 不需要 |
| 加密 | Binance（备用 Binance 镜像 / OKX） | 不需要 |
| 黄金 | gold-api.com 现货金价（可直接按 CNY 等币种报价），备用 Binance PAXG/USDT；代码填 XAU | 不需要 |
| 股票 / 基金 | Finnhub（推荐）/ Twelve Data / Alpha Vantage | 需要免费注册 |

Finnhub Key：https://finnhub.io/register 注册 → 复制 API Key → 粘到「数据设置 → 行情源配置」。

## 四、盈亏口径

- **日盈亏**：现价 − 昨收（股票 / 基金）或今日开盘价（加密、黄金）；手动维护的资产与前一天记录比较。
- **月 / 年盈亏**：现价 − 上月末 / 去年末记录价；期内新录入的资产从录入时价格起算。
- **现金、负债、记账收支、转账不计入盈亏**；它们只影响总资产。
- **日变化排行 / 今日盈亏列**：包含现金余额变化（记账同步、转账、手动更新余额）。
- **总资产 = 所有资产 + 负债（负数）**，即净资产。

## 五、锁定与操作记录

- 资产明细、收支明细默认锁定；编辑 / 删除需要密码，验证后在设定时间内保持解锁。
- “锁仓”资产每次编辑 / 删除 / 解除锁仓都要重新输入密码。
- 每条资产 / 记账都有操作记录（时钟图标），「数据设置 → 操作日志」可查看全部（含已删除）。
- 密码只以哈希保存在本机，导出与同步都不含密码。忘记密码：清空本地数据 → 导入备份 → 重设。

## 六、配置 GitHub 多端同步（电脑 + 手机）

同步分两部分：**① 让手机也能打开 AssetHub（网址）**，**② 让各设备共用同一份数据（Gist）**。

### 第 1 步：把 AssetHub 挂到网上（GitHub Pages，只做一次）

1. 登录 https://github.com （没有账号先免费注册）。
2. 右上角「+」→ **New repository**：名称填 `assethub`，选 **Public**，点 **Create repository**。
3. 在新仓库页面点 **uploading an existing file**（或 Add file → Upload files），
   把 **AssetHub 文件夹里面的全部内容**（index.html、assets 文件夹、README.md、.nojekyll）拖进去 → **Commit changes**。
   > 注意是文件夹里面的内容，不是 AssetHub 文件夹本身；上传后仓库首页应直接看到 index.html。
4. 仓库 **Settings → Pages** → Source 选 **Deploy from a branch**，Branch 选 **main**、文件夹 **/ (root)** → **Save**。
5. 等 1～2 分钟，页面顶部会出现网址：`https://你的用户名.github.io/assethub/`。电脑和手机都用这个网址打开。
   > 仓库里只有程序代码，**没有你的任何资产数据**，公开也没关系。

### 第 2 步：创建 GitHub Token（只需 gist 权限）

1. 打开 https://github.com/settings/tokens/new?scopes=gist&description=AssetHub
   （或 AssetHub 里「数据设置 → 多端同步 → 一键创建 Token」）。
2. Note 填 `AssetHub`，Expiration 选 **No expiration**（或 1 年），**只勾选 gist**。
3. 点 **Generate token**，复制以 `ghp_` 开头的 Token（只显示一次，先存到备忘录）。

### 第 3 步：电脑上首次上传

1. 用第 1 步的网址打开 AssetHub。
   > 如果你之前是双击本地文件使用的，先在本地版「数据设置 → 导出数据」，再到网址版「导入数据」，把数据搬过去。
2. 「数据设置 → 多端同步」粘贴 Token。
3. 点右上角 **云朵按钮**，系统会自动创建私有 Gist 并上传，Gist ID 会自动填好。把 Gist ID 复制下来。

### 第 4 步：手机上拉取

1. 手机浏览器打开同一个网址（Safari / Chrome 可「添加到主屏幕」，像 App 一样使用）。
2. 「数据设置 → 多端同步」粘贴**同一个 Token** 和 **Gist ID**，系统会自动拉取，数据就和电脑一致了。

### 之后的日常

- **自动同步**：打开页面时自动拉取；新增 / 修改资产或记账后 3 秒自动上传；切回页面时再检查一次。
- **手动同步**：点右上角云朵。小圆点：绿 = 已同步，橙 = 有改动待上传，红 = 失败（悬停看原因），灰 = 未设置。
- **两边都改过**：会弹窗让你选「保留云端」或「保留本机」。
- **同步失败**：GitHub 偶发 HTTP 500 会自动重试 3 次；错误提示会说明原因（Token 失效 / Gist ID 不对 / 网络等）。
  一直 HTTP 500 时，点「数据设置 → 多端同步 → 新建 Gist」重新上传，再把新的 Gist ID 填到其他设备。
- 同步资产、记账、账本信息、操作日志和行情 API Key（Finnhub / Twelve Data / Alpha Vantage，以最后修改的为准）；锁定密码随加密同步统一。布局、配色、语言和 GitHub Token 各设备独立。导出的备份文件不含任何 Key。

### 安全提示

- Token 只有 gist 权限，只保存在你自己的浏览器里，不会被导出或上传。
- Gist 是“私密链接”（secret），不会被搜索到，但**知道 Gist 链接的人可以看到内容**，请勿外传 Gist ID。
- 换手机或怀疑泄露：到 https://github.com/settings/tokens 删除旧 Token，重新生成一个即可。

## 七、常见操作

- **更新手动资产**：资产明细里点「更新」输入今天的持有总金额；现金点「余额」。
- **录错导致今日盈亏虚高**：资产明细「今日盈亏」列点「清零」，以当前值作为今天的起点（只对手动维护 / 现金类资产显示）。当天新录入的手动资产，当天用「编辑」修改不会计入今日盈亏。
- **加仓 / 减仓**：用「编辑」改数量和成本，不要用「更新」（否则会被当成盈利）。
- **转账（任意资产互转）**：收支明细 →「转账」。现金 / 负债按金额，其他资产按数量（如 0.1 BTC）；到账数量按现价自动折算，可手动改。
  转入股票 / 加密等资产时，按转出部分的成本摊入平均成本；手续费按价值计入支出；删除或修改转账会完整回滚数量与成本。
- **资产仓库**：添加资产时可一键选择预设仓库（Binance、BIT、OKX、Bitget Wallet、fomo、支付宝、微信、各银行卡），预设列表在 app.js 顶部 `WAREHOUSE_PRESETS`。
- **备份**：「数据设置 → 导出数据」得到 JSON 文件，建议定期保存。

## 八、数据安全（v3.1）

- **自动备份**：加载演示、导入、清空、云端覆盖、恢复之前，都会自动备份当前数据（本机保留最近 10 份）。
- **新建空白账本**：「数据设置 → 新建空白账本」清空本机数据（自动备份）、不加载演示，并新建一个空白 Gist；原 Gist 保留，重新填入原 Gist ID 即可切换回去。
- **清空本地数据**：只清数据，保留 Token / 密码 / 偏好设置，并断开当前 Gist（避免云端旧数据又被拉回来）。
- **数据恢复**：「数据设置 → 数据恢复」可从本机备份、旧版 AssetView 数据、或云端 Gist 的任意历史版本一键恢复。
- **演示数据不会覆盖云端**：本机是演示数据而云端是真实数据时，不会自动上传；手动上传也会二次确认。
- **云端加密 + 密码同步**：上传到 Gist 的数据用锁定密码加密（PBKDF2 + AES-GCM），别人拿到 Gist 链接也只看到乱码。
  新设备第一次同步时输入同一个密码，解密成功后该设备的锁定密码自动改成相同的。
  修改密码后云端会自动用新密码重新加密，其他设备下次同步时会要求输入新密码。
- **忘记密码**：云端加密数据无法解开；只要任意一台设备上数据还在，在那台设备「清空 → 导入备份 → 重设密码 → 新建 Gist」即可。建议定期「导出数据」做离线备份（导出文件不加密，请妥善保管）。
